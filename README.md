# Industrial Plenoptic Dataset (IPD)

> [!IMPORTANT]
> **This repository is no longer maintained.**
>
> The original download links and the toolkit scripts that depended on them no
> longer work. The IPD dataset is now hosted by the
> [BOP benchmark](https://bop.felk.cvut.cz/) on Hugging Face:
>
> ### 👉 https://huggingface.co/datasets/bop-benchmark/ipd
>
> Please go there for download instructions, the dataset description and its
> license.

The data is provided in the standard BOP format. You can use the
[BOP toolkit](https://github.com/thodan/bop_toolkit) to read, visualize and
evaluate on it. The format is described in the
[BOP datasets format documentation](https://github.com/thodan/bop_toolkit/blob/master/docs/bop_datasets_format.md).
